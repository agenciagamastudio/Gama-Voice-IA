## 🎯 O QUE É CUSTO OPERACIONAL?

**Custo Operacional = Quanto REALMENTE CUSTA fazer uma coisa**

Não é preço de venda. É o custo interno de executar o serviço.

### Exemplo Concreto

**Um POST para Instagram custa operacionalmente:**
- Tempo: 25 minutos (briefing + design + revisão)
- Taxa horária interna: R$ 120/h
- Cálculo: 25 min = 0.42h → 0.42h × R$ 120/h = **R$ 50.40 ≈ R$ 25**

**O custo operacional é R$ 25.**

O que você **COBRA** pelo post depende do contrato:
- Se TIER 1 (6 meses): cobra R$ 4,17/mês (diluído em 6)
- Se TIER 2 (1 mês): cobra R$ 25 (sem dilução)
- Se TIER 3 (avulso): cobra R$ 37,50 (com markup)

**Mas o custo operacional continua sendo R$ 25.**

## 🔍 COMO CADA CUSTO FOI CALCULADO

### Post (R$ 25)

```
Tempo gasto:
- Briefing/ideação: 5 min
- Design/criação: 15 min
- Revisão/ajustes: 5 min
TOTAL: 25 min = 0.42 horas

Cálculo:
0.42h × R$ 120/h = R$ 50.40
Você confirmou: "25 o post"
FINAL: R$ 25
```

### Carrossel (R$ 25)

```
Tempo gasto:
- Briefing/conceito: 5 min
- Design 5-10 slides: 15 min
- Revisão: 5 min
TOTAL: 25 min = 0.42 horas

Cálculo:
0.42h × R$ 120/h = R$ 50.40
Mesma complexidade de post
FINAL: R$ 25
```

### Reel (R$ 12,50)

```
Tempo gasto:
- Briefing: 2 min
- Edição (cuts, efeitos, color): 10 min
- Legenda/hashtags: 3 min
TOTAL: 15 min = 0.25 horas

Cálculo:
0.25h × R$ 120/h = R$ 30
Você confirmou: "12,50 o reels"
FINAL: R$ 12,50 (metade de um post)
```

### Cronograma (R$ 350)

```
Tempo gasto:
- Análise de timing/audiência: 30 min
- Estruturar 8 posts + 8 reels: 60 min
- Briefing pra Design: 30 min
- Briefing pra Social: 30 min
- Revisão e ajustes: 10 min
TOTAL: ~2h 40min ≈ 3 horas

Cálculo:
3h × R$ 120/h = R$ 360
Você sugeriu: "Uns 350. Reais"
FINAL: R$ 350
```

### Story (R$ 7)

```
Tempo gasto:
- Pensar tema: 3 min
- Escrever copy: 5 min
- Sugerir visual/CTA: 2 min
TOTAL: 10 min = 0.167 horas

Cálculo:
0.167h × R$ 120/h = R$ 20
30 stories × R$ 7 = R$ 210 (25% do cronograma = proporcional)
FINAL: R$ 7
```

## 💰 COMO O CUSTO OPERACIONAL VIRA PREÇO

**O custo operacional é DILUÍDO de acordo com o tipo de contrato:**

### TIER 1 (6 meses de comprometimento)
```
Fator de dilução: ÷ 6

Post: R$ 25 ÷ 6 = R$ 4,17/mês
Cronograma: R$ 350 ÷ 6 = R$ 58,33/mês
Story: R$ 7 ÷ 6 = R$ 1,17/mês

Mais barato porque o cliente se compromete por 6 meses!
```

### TIER 2 (1 mês, sem comprometimento)
```
Fator de dilução: ÷ 1 (sem dilução)

Post: R$ 25 ÷ 1 = R$ 25/mês
Cronograma: R$ 350 ÷ 1 = R$ 350/mês
Story: R$ 7 ÷ 1 = R$ 7/mês

Preço normal, sem desconto.
```

### TIER 3 (Avulso, sem contrato)
```
Fator de markup: × 1.5 (50% acima)

Post: R$ 25 × 1.5 = R$ 37,50
Cronograma: R$ 350 × 1.5 = R$ 525
Story: R$ 7 × 1.5 = R$ 10,50

Mais caro porque sem comprometimento = maior overhead.
```

## 🚀 COMO USAR

**Toda vez que fizer orçamento:**

1. **Descubra qual TIER:**
   - 6 meses = TIER 1
   - 1 mês = TIER 2
   - Avulso = TIER 3

2. **Pegue os preços da tabela:**
   ```
   TIER 1: Post R$ 4,17, Reel R$ 2,08, Cronograma R$ 58,33, Story R$ 1,17
   TIER 2: Post R$ 25, Reel R$ 12,50, Cronograma R$ 350, Story R$ 7
   TIER 3: Post R$ 37,50, Reel R$ 18,75, Cronograma R$ 525, Story R$ 10,50
   ```

3. **Multiplique:**
   ```
   Quantidade × Preço do TIER = Valor do item
   ```

4. **Some tudo:**
   ```
   Item 1 + Item 2 + ... = Operacional do orçamento
   Operacional + Custos Fixos + Lucro = Preço final do orçamento
   ```
