## Como Usar no GAMA_ORÇAMENTO

### Ao criar novo orçamento:
1. Abra `/novo-orcamento`
2. Selecione cliente
3. Clique "+ Adicionar Item"
4. Escolha o **código** (POST-SMP, REEL-60, etc)
5. Quantidade
6. Sistema calcula preço automaticamente (conforme tier)
7. Pronto!

### Exemplo:
- Cliente: Engy Solar (TIER 1)
- 8× POST-SMP → R$ 500 = R$ 4.000
- 2× REEL-60 → R$ 1.000 = R$ 2.000
- 1× CM-MES (Padrão) → R$ 2.200
- **Total: R$ 8.200**
