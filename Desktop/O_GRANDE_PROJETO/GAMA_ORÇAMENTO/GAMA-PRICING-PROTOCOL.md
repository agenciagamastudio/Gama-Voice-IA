# 🎯 GAMA PRICING PROTOCOL v1.0

**Cole este prompt em qualquer chat (Claude, ChatGPT, Copilot, etc) para precificar seus serviços anatomicamente.**

---

## 📋 PROMPT (Copie e Cole)

```
VOCÊ ESTÁ AJUDANDO A PRECIFICAR SERVIÇOS DE UMA AGÊNCIA DE SOCIAL MEDIA + DESIGN CHAMADA GAMA STUDIO.

CONFIGURAÇÃO:
- Taxa Horária: R$ 120/hora
- Overhead: 10%
- Margem: 50%
- Softwares usados: Adobe, Canva, CapCut, Meta Business Suite

QUANDO O USUÁRIO DISSER UM SERVIÇO (post, reel, carrossel, fotografia, consultoria, etc):

1. RETORNE UMA LISTA DE COMPONENTES COM TEMPO ESTIMADO:
   - Listar cada tarefa que envolve aquele serviço
   - Tempo estimado para cada uma (em minutos)
   - Software principal usado

2. O USUÁRIO MARCA COM "X" O QUE FAZ PARTE:
   - Ele copia, marca as tarefas relevantes, cola de volta

3. VOCÊ CALCULA:
   - Total de horas (somando minutos marcados)
   - Custo de Execução: Horas × R$ 120
   - + Softwares (rateio pequeno, ~R$ 5-15)
   - + Overhead (+10%)
   - + Margem (+50%)
   - = PREÇO FINAL

4. MOSTRE A DECOMPOSIÇÃO CLARA (quanto de cada componente contribui)

QUANDO RETORNAR:
✅ Listar componentes com tempo
✅ Calcular preço final quando marcado com X
✅ Mostrar quanto cada parte (design, social, etc) contribui
✅ Sugerir preço mensal se o cliente usa esse serviço 4-8x/mês
```

---

## 🚀 COMO USAR

1. **Copie o prompt acima** (de "```" até o final)
2. **Abra um chat** (Claude, ChatGPT, Copilot, qualquer um)
3. **Cole o prompt**
4. **Depois escreva o serviço que quer precificar:**
   - `post`
   - `reel`
   - `carrossel`
   - `fotografia`
   - `consultoria`
   - `community management`
   - Ou qualquer outro

5. **O chat retorna a lista** com componentes e tempos
6. **Você marca com X** o que é relevante
7. **Cola de volta** 
8. **Pronto** — ele calcula o preço final!

```
