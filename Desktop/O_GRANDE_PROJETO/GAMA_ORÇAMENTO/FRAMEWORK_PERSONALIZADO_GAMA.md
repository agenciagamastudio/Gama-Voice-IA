## 💰 COMO OS PREÇOS FORAM CALCULADOS

### STARTER: R$ 1.8k/mês

```
Custo operacional:
├─ 2 reels × R$ 12,50 = R$ 25
├─ Cronograma (30% do fixo) = R$ 105
├─ Stories (caso inclua) = R$ 50
└─ Overhead/admin = R$ 100
   ─────────────────────────
   Total custo = R$ 280

Preço: R$ 1.8k
Margem: (R$ 1.8k - R$ 280) / R$ 1.8k = 84% ← SAUDÁVEL

Ideal pra: Clientes pequenos testando, Tier 3 existentes que querem roupa mais básica
```

### GROWTH: R$ 2.8k/mês (Recomendado para maioria)

```
Custo operacional:
├─ 4 reels × R$ 12,50 = R$ 50
├─ Cronograma completo = R$ 350
├─ 1 call mensal = R$ 100
└─ Overhead = R$ 150
   ─────────────────────────
   Total custo = R$ 650

Preço: R$ 2.8k
Margem: (R$ 2.8k - R$ 650) / R$ 2.8k = 77% ← MUITO BOM

Ideal pra: 80% dos clientes atuais, sweet spot preço/valor
```

### SCALE: R$ 4.5k/mês (Premium)

```
Custo operacional:
├─ 6 reels × R$ 12,50 = R$ 75
├─ Cronograma completo = R$ 350
├─ 2 calls + consultoria (10h) = R$ 1.2k
├─ Relatório + analytics = R$ 200
└─ Overhead = R$ 250
   ─────────────────────────
   Total custo = R$ 2.075

Preço: R$ 4.5k
Margem: (R$ 4.5k - R$ 2.075) / R$ 4.5k = 54% ← BUSCÁVEL AINDA

Ideal pra: Clientes Tier 1 (>R$ 50k faturamento), que precisam de consultoria estratégica
```

## 🔄 CAMADA 3: PERFORMANCE BONUS (Coração do Framework)

**Por que existe:**
- Alinha seus incentivos com os do cliente
- Transforma "cobro por reel" em "ganho se reel vende"
- Permite margens muito maiores se conseguir provar valor

**Como funciona:**

```
Pré-requisito: Cliente tem rastreamento setup (UTM + GA4 + Shopify)

Oferta:
"Este trimestre, vamos medir impacto real dos reels.

Se conseguir comprovar que geraram > R$ 100k em vendas rastreáveis,
você nos paga um bônus de R$ 2k (2% do faturamento extra).

Benefício pra você:
├─ Se reels forem ruins: você não paga nada extra
├─ Se reels forem bons: você paga bônus (ainda vale a pena)
└─ GAMA só ganha bônus se resultado for real

Benefício pra GAMA:
├─ Prova valor tangível
├─ Justifica preço premium no trimestre seguinte
├─ Pode vender "reels que vendem" vs "reels genéricos"
└─ Próximo contrato: +50% de preço porque provou resultado"

Implementação:
1. Setup UTM em todo reel (utm_source=gama_reel, utm_campaign=reel_nome)
2. Integração Shopify → Google Sheets (rastrear origem da venda)
3. Relatório mensal: "Seus reels geraram X vendas em Y traffic"
4. Ao fim do trimestre: if (vendas > meta) → GAMA ganha bônus
```

**Exemplo prático:**

```
Cliente: Loja de roupas, faturamento R$ 500k/ano
Contrato GROWTH: R$ 2.8k/mês (padrão)

TRIMESTRE 1 (sem bônus):
- GAMA cobra: R$ 2.8k × 3 = R$ 8.4k
- Reels geram: R$ 120k em vendas rastreáveis
- Resultado: GAMA ganhou R$ 8.4k

TRIMESTRE 2 (com bônus estruturado):
- Meta: se vendas > R$ 100k, bônus = 2% daquele faturamento
- GAMA cobra: R$ 2.8k × 3 = R$ 8.4k
- Reels geram: R$ 150k em vendas rastreáveis
- GAMA ganha bônus: R$ 150k × 2% = R$ 3k
- TOTAL: R$ 8.4k + R$ 3k = R$ 11.4k naquele trimestre

TRIMESTRE 3 (cliente percebeu valor):
- Cliente quer renovar
- GAMA negocia: "Provou que reels valem, vamos pra R$ 4k/mês (SCALE)"
- Novo contrato: R$ 4k × 3 = R$ 12k (vs R$ 8.4k antes)
- +43% de receita anual com mesmo cliente
```

## ⚠️ Riscos e Como Mitigar

### Risco 1: Cliente Reclama "Aumentou Muito"
**Mitigação:**
```
Ser direto: "Sim, aumentou. Porque antes você pagava por hora indefinida.
            Agora você sabe o preço fixo, e nós sabemos exatamente
            quanto vamos trabalhar. Isso é bom pra ambos.
            
            Se quiser continuar com R$ 120/h, podemos fazer,
            mas precisa entender que no fim vai pagar mais
            porque sem escopo fixo, não tem limite de horas."
```

### Risco 2: Cliente Sai
**Resposta esperada:**
```
Sim, alguns vão sair. Normal. Isso é esperado.
Pense assim: você prefere 10 clientes em R$ 1.5k/mês
              ou 6 clientes em R$ 2.8k/mês?

Matemática:
Antes:  10 × R$ 1.5k = R$ 15k/mês (56% de margem = R$ 8.4k lucro)
Depois: 6 × R$ 2.8k = R$ 16.8k/mês (77% de margem = R$ 12.9k lucro)

Resultado: +53% de lucro, com 4 clientes a menos = melhor vida
```

### Risco 3: Rastreamento é Difícil
**Mitigação:**
```
Start com clientes que já têm Shopify + GA4 setup.
Clientes pequenos que só têm Instagram: sem bônus de performance.
Isso é OK. 70% pode ter bônus, 30% não.

Depois, quando tiver 10 clientes em novo modelo,
GAMA contrata alguém só pra fazer setup de rastreamento
(paga pelo valor que vai gerar nos bônus de performance).
```
