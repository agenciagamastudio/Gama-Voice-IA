# CONTRATO DE RENOVAÇÃO ANUAL
## Fotografia de Aniversário (12 Meses Depois)

**Tipo de Documento:** Template para re-engagement + contrato simplificado
**Baseado em:** Case Study Estefany Raielly
**Timeline:** Enviar 1 mês antes da data do aniversário de 1 ano
**Objetivo:** Converter cliente recorrente + aumentar ticket com desconto de fidelidade

---

## 📧 FASE 1: EMAIL/WHATSAPP DE RE-ENGAGEMENT

### TIMING
**Data de Envio:** Exatamente 1 mês antes do aniversário
- Exemplo: Estefany 1º aniversário = 16/05/2027 → enviar 16/04/2027

### OBJETIVO
- Reativar cliente com lembrança emocional
- Criar urgência ("Já faz 1 ano!")
- Oferecer promocão especial (desconto + bônus)
- Posicionar renovação como natural (não venda agressiva)

### TEMPLATE DE EMAIL/WHATSAPP

```
[Nome]! 1 ANO! 🎂🎉

Não acredito que já faz 1 ano que fotografei a festa 
de [nome da criança]!

Como está essa pequena/pequeno? Cresceu! 💚

---

Se vocês vão fazer o 2º aniversário (ou festa especial), 
queria muito fotografar de novo!

Tenho um presente especial pra você:

🎁 PACOTE RENOVAÇÃO (Só pra clientes antigos):

📸 Retraço do 1º ano -- 1 sessão fotográfica
📸 Edição "antes & depois" (1º vs 2º ano)
📸 15% de desconto na cobertura do 2º aniversário
📸 + 10 prints GRÁTIS (ao invés de R$100)

Tudo por R$ 650 (antes seria R$ 900)

---

Marca um tempo comigo? 
Essa data pra mim é especial! ❤️

Abraços,
[Seu nome]
```

### VARIAÇÃO 1: Se Cliente NÃO Faz 2º Aniversário

Se cliente responder "Não vamos fazer festa de 2 anos":

```

com tema especial de "1 Ano".

Interesse?
```

### VARIAÇÃO 2: Se Cliente Quer Renovar

Se cliente responder com entusiasmo:

```

Então vamos assim:

OPÇÃO 1: Só 2º aniversário -- R$ 350 (cobertura evento)

OPÇÃO 3: Completo -- R$ 900 (cobertura + estúdio + lembrancinhas)

Qual você acha melhor?

P.S.: Temos 15% OFF pra você (cliente antigo)! 💚
```

**Por que simplificado?**
- Cliente já conhece você (não precisa explicar tudo)
- Reutiliza informações do contrato anterior

## 📊 POLÍTICA DE DESCONTO RECORRENTE

### ESTRUTURA DE DESCONTOS

| Cliente | Status | Desconto | Benefício Extra |
|---------|--------|----------|-----------------|
| 1º evento | Novo | 0% | — |
| 2º evento (1 ano depois) | Recorrente | 15% | +10 prints |
| 3º evento (2 anos depois) | VIP | 20% | +15 prints + álbum |
| 4º+ evento | Super VIP | 25% | +20 prints + álbum + sessão extra grátis |

### IMPLEMENTAÇÃO

Ao enviar contrato de renovação, mencionar:
```
Você é cliente desde [data 1º evento].

Por isso, oferecemos 15% de desconto + bônus (10 prints grátis).

Valor: R$ 650 (antes seria R$ 900)

Só pra quem chegou até aqui comigo! 💚
```

## 🎯 MÉTRICAS DE SUCESSO

Após implementar este POP:

| Métrica | Target |
|---------|--------|
| % de clientes que renovam | 40%+ |
| Tempo de reativação (contato → confirmação) | <7 dias |
| Aumento de ticket (renovação vs 1º) | +30% |
| Indicações de clientes recorrentes | 2+ por cliente |
| Desconto executado corretamente | 100% |

---

## ⚠️ ERROS A EVITAR

| Erro | Impacto | Como Evitar |
|------|--------|-----------|
| Enviar email caro genérico ("Faça fotos novamente!") | Cliente se sente número | Personalizar: mencionar nome criança, 1º ano |
| Não oferecer desconto | Cliente acha caro renovar | Sempre 15%+ para recorrente |
| Esperar cliente cobrar estúdio de novo | Cliente frustrada | VOCÊ toma iniciativa (1 mês antes) |
| Não pedir indicação de recorrente | Perde crescimento | Perguntar sempre, sem vergonha |
| Entregar sem "antes & depois" | Perde momento emocional | Criar slide 1º vs 2º ano |
