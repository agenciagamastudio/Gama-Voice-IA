## 💡 PRINCIPAIS INSIGHTS DO CASO ESTEFANY

### O Que Funcionou Bem (Replique Sempre)
✅ **Qualificação antes de preço** — Fez 5 perguntas ANTES de cotar  
✅ **Portfólio com humanização** — "Cor de pele linda" criou conexão  
✅ **Upsell como "dica"** — Cliente não resistiu (conselho, não venda)  
✅ **Desconto justificado** — Âncora (R$350) → redução lógica (fácil)  
✅ **Benefício de lealdade** — "Como já contratou, preço especial"  
✅ **Conversão rápida** — 27 min para aceitar proposta (warm lead)  

### O Que Deixou a Desejar (Não Repita)
❌ **Lembrancinhas sem preço** — Mencionadas, mas nunca documentado  
❌ **Sem contrato escrito** — Tudo verbal/WhatsApp (risco legal)  
❌ **Fotógrafo demorou responder** — Cliente teve que chamar várias vezes  
❌ **Sem post-delivery plan** — Não pediu depoimento nem indicações
