## 🏗️ Geração Mockup-por-Mockup

### PRODUTO 1: CARTÃO DE VISITA PREMIUM

**Prompt (copiar/colar direto):**
```
A stack of premium business cards (cartões de visita) fanned out slightly, 
white background, professional studio lighting from top-right at 45 degrees, 
realistic shadow underneath, sharp focus on card details and texture, 
corporate photography style, 8k quality, dramatic lighting that emphasizes 
paper texture and finish. Details: Card should show embossing, subtle color 
variations (Quadricolor CMYK reference), and premium finish (matte or glossy).
```

**Configurações Nano Banana:**
- **Quality:** Ultra (8k)
- **Aspect Ratio:** 1:1
- **Style:** Product Photography
- **Iterations:** 3 (escolher melhor)

**Resultado esperado:** Stack de cartões com sombra, lighting dramático

**Após gerar (refinamento):**
1. Download PNG
2. Abrir em Photoshop/GIMP
3. Levels → Branco para #FFFFFF
4. Salvar como:
   - `product-cartao-premium-branco.png` (transparente)
   - `product-cartao-premium-branco.jpg` (fundo branco)
5. Copiar para: `quadricolor._/site/public/products/cartao-de-visita/`

## 🎨 Pós-Processamento em Lote (Photoshop Batch)

Se quer acelerar os refinamentos, crie uma Action no Photoshop:

```
1. File → Automate → Create Droplet
2. Defina ações:
   - Levels: Branco para #FFFFFF
   - Hue/Saturation: +10 saturation
   - Export como PNG e JPG

3. Depois é só arrastar pastas de imagens
```

## 💡 Dicas & Truques

### Se o fundo ficar cinzento:
- Use **Curves** em vez de Levels
- Puxe ponto branco para #FFFFFF exato
- Ou: Select by Color (branco) → Levels

### Se a sombra for muito fraca:
- Duplique a camada de sombra
- Aumente opacity para 50-60%
- Ou: Gaussian Blur aumentado (15-20px)

### Se cores estiverem pálidas:
- Hue/Saturation: +15 a +20
- Vibrancy: +10 (realça cores naturais)
- Color Balance: Shift para core colors (reds, yellows) se necessário

### Se Nano Banana gerar artefatos:
- Tente novamente (iterations 2-3)
- Ajuste prompt (remova/mude detalhes conflitantes)
- Use Magic Wand para limpar áreas com glitch
