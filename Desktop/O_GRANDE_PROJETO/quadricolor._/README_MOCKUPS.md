## 🎯 O Que É Este Sistema?

Um **padrão visual e workflow completo** para gerar mockups de produtos (cartão de visita, camiseta, abadá, banner, brindes, adesivos, comunicação visual) usando **Nano Banana** (gerador de imagens com IA).

### Objetivos:
✅ Padronização visual consistente  
✅ Fundo branco + sombra e iluminação 3D marcada  
✅ Escalável para futuras variações  
✅ Profissional e corporativo  
✅ Rápido de executar (2-3 min por mockup)

## ⚡ Quick Start (5 minutos)

### 1. Preparação
```bash
# Terminal: criar pastas de destino
cd "C:\Users\Usuario\Desktop\O_GRANDE_PROJETO\quadricolor._\site\public\products"

mkdir -p cartao-de-visita camisa-personalizada abadaq-junino \
         banner-lona brinde-personalizado adesivo-vinil comunicacao-visual
```

### 2. Primeira Geração
```
1. Abra Nano Banana (URL/login)
2. Nova geração
3. Copie prompt de NANO_BANANA_PROMPTS.md
4. Configurações: Ultra, 1:1, Product Photography, 3 iterations
5. Gerar
6. Escolher melhor resultado
7. Download PNG
```

### 3. Refinamento (Photoshop/GIMP/Canva)
```
1. Abrir PNG em Photoshop
2. Levels → Branco para #FFFFFF
3. Ajustar cores se necessário (+10 saturação)
4. Exportar:
   - PNG (transparente): product-[categoria]-[variante].png
   - JPG (fundo branco): product-[categoria]-[variante].jpg
5. Salvar em: site/public/products/[categoria]/
```

### 4. Validação
Checklist de 5 itens:
- ✅ Fundo branco puro
- ✅ Sombra realista embaixo
- ✅ Resolução 1200x1200 px
- ✅ Arquivo < 500 KB
- ✅ Nomeação padrão

### Visual
```
Fundo:        Branco puro (#FFFFFF)
Lighting:     45° top-right (profissional)
Sombra:       Realista embaixo (~30px blur)
Estilo:       Corporativo, fotográfico, 8k
```

```
Formato:      PNG (transparente) + JPG (branco)
```

## ❓ Dúvidas Frequentes

### P: "Quanto tempo leva para gerar um mockup?"
**R:** Nano Banana leva ~30-60 segundos por iteração. Com 3 iterações = ~2 min. Refinamento = 5-10 min. Total = ~15 min por produto.

### P: "Posso gerar sem Photoshop?"
**R:** Sim! Use Canva Pro, GIMP ou Pixlr. Os passos são similares (ajustar branco, saturação, exportar).

### P: "E se o Nano Banana não gerar bem na primeira vez?"
**R:** Tente novamente (diferentes seeds), ou ajuste o prompt (remova detalhes conflitantes).

### P: "Preciso comprar Nano Banana?"
**R:** Depende do modelo. Pesquise preços atuais. Algumas alternativas têm versão free.

### P: "Posso usar essas imagens em redes sociais?"
**R:** Sim! Exporte JPG 1200x1200. Instagram/Facebook aceitam bem esse tamanho.

### P: "Como manter a consistência entre produtos diferentes?"
**R:** Use o mesmo prompt de lighting (45° top-right), mesma resolução (1200x1200), mesma paleta de cores (CMYK Quadricolor).
